# 连杆热模锻工艺卡

文件号 HD-P1-PC-031　版本 B　适用：一厂连杆 1 线、连杆 2 线　产品：连杆 LG-B20（材料 C70S6 胀断钢，锻件重 0.62 kg，下料重 0.74 kg）　客户：远岳动力

## 1 设备

连杆 1 线：SAW-501、IH-501、RF-501、HP-501、TP-501、CL-501、SB-501、MT-501、PK-501。
连杆 2 线：SAW-601 … PK-601，配置相同。

## 2 关键参数

| 工序 | 参数 | 要求 |
|---|---|---|
| 加热 | 出炉温度 | 1200～1250 ℃ |
| 热模锻 | 节拍 | 12 s/件 |
| 热模锻 | 大头厚度（热态） | 22.0 mm，范围 21.6～22.4 mm |
| 热模锻 | 模具预热 | 200～250 ℃ |
| 切边 | 切边模寿命 | 30000 件 |
| 控冷 | 冷却方式 | 控制风冷，保证胀断性能，冷速按工艺卡曲线 |

## 3 大头厚度

- 大头厚度在压力机出口热态测量，每件记录（压力机测量值上传孪生，Modbus 测量寄存器）。
- 偏下限（< 21.6 mm）判“充不满”，偏上限（> 22.4 mm）判“尺寸超差（模膛磨损）”。
- 厚度随模具磨损逐渐上移。连续 5 件超过 22.3 mm 时通知换模，不等超差。

## 4 模具寿命与换模

- 终锻模设计寿命 14000 件，换模用时约 60 分钟，备件为连杆终锻模（每副约 5000 元）。
- 计划换模点：寿命的 85%（11900 件）。如果大头厚度上漂早于这个点，以厚度为准提前换模。
- 换模后首件三检，并复检换模前最后 200 件的大头厚度记录。

## 5 胀断钢注意事项

C70S6 对冷却速度敏感：冷速过快硬度高、胀断面不平；过慢晶粒粗。控冷线风机故障时该批次单独标识，送理化室做硬度和金相。
