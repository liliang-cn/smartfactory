# 辗环件检验标准

文件号 HD-P2-QS-007　版本 A　适用：二厂法兰 1～3 线、套圈 1～2 线

## 1 风电法兰 FL-1200-Q355（材料 Q355NE，锻件重 312 kg）　客户：北辰风电

| 项目 | 要求 | 检测方法与频次 |
|---|---|---|
| 正火硬度 | 150～190 HB，目标 170 HB | 布氏硬度计，每炉 3 件，每件 3 点 |
| 端面平面度 | ≤ 0.15 mm（目标 0.05 mm） | 数控车床在线测量，每件 |
| 超声探伤 | 按 EN 10228-3 质量等级 3 | 100%，UT-101～UT-301 |
| 低温冲击 | -20 ℃ KV2 ≥ 27 J | 每炉随炉试样 |

- 硬度偏低或偏高的件可重新正火返修一次，返修后复测，仍不合格判废。
- 平面度超差多与数控车床刀具磨损有关，刀具按寿命计数更换（每把约 40 件）。

## 2 轴承套圈 TQ-320-W（材料 GCr15，锻件重 12.8 kg）　客户：凯沃轴承

| 项目 | 要求 | 检测方法与频次 |
|---|---|---|
| 外径 | 320.0 ± 0.2 mm | 尺寸视觉检测 VI-401、VI-501，每件 |
| 球化组织 | 按 JB/T 1255 2～4 级 | 每批抽 2 件金相 |
| 表面裂纹、折叠 | 不允许 | 目视 + 磁粉抽检 |

- 外径随辗环机测量辊和芯辊磨损逐渐偏移，连续 5 件偏同一侧超过 0.15 mm 时通知设备调整。

## 3 标识与追溯

每件打钢印：零件号、炉号、热处理炉次、日期。超声和硬度报告按炉号归档，随货提供材质证明和探伤报告。
