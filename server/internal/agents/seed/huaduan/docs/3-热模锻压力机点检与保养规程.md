# 热模锻压力机点检与保养规程

文件号 HD-EQ-MS-004　版本 D　适用：一厂热模锻压力机 HP-101～HP-601、切边冲孔压力机 TP-101～TP-601

## 1 班前点检（操作工，10 分钟）

| 项目 | 标准 | 不合格处理 |
|---|---|---|
| 润滑油位 | 油标 1/2～2/3 | 补油，记录 |
| 平衡缸气压 | 0.45～0.55 MPa | 低于 0.40 MPa 不得开机，报设备科 |
| 离合器、制动器 | 空行程 3 次，制动角 ≤ 15° | 制动角超标停机 |
| 模具紧固螺栓 | 无松动 | 按扭矩表紧固 |
| 安全光栅、双手按钮 | 动作正常 | 不得屏蔽，报修 |

## 2 运行监控

- 机身温度（孪生“温度”）：正常 ≤ 60 ℃，72 ℃ 预警，84 ℃ 自动停机。
- 主电机功率：空载约 40 kW，满负荷约 260 kW。持续高于额定值 10% 检查打击力设定和坯料温度。
- 振动：日常基线由孪生记录；比基线高 30% 以上即安排检查，常见原因为导轨间隙变大、地脚螺栓松动。
- 健康度（孪生“健康”）低于 60% 时，下一个班次安排预防性检查。

## 3 常见报警处理

### 3.1 滑块平衡缸压力低
检查气源压力、平衡缸密封和管路泄漏。气压恢复到 0.45 MPa 以上，空行程 3 次正常后复位。

### 3.2 模具温度过低
模具温度低于 150 ℃ 时报警。停止锻打，用烘枪补热到 200 ℃ 以上；连续出现说明润滑喷涂量过大或节拍过慢，通知工艺员。

### 3.3 离合器制动异常
立即停机挂牌，不得复位后继续生产。设备科检查摩擦片磨损、制动气缸和电磁阀，测量制动角合格后由设备科复位。

## 4 周保养（设备科）

- 导轨间隙检测，超过 0.3 mm 调整。
- 离合器摩擦片厚度测量，剩余 < 3 mm 更换。
- 液压过载保护装置试验一次。
- 集中润滑系统清洗滤芯。

## 5 年度保养

每年一次大修窗口（一般在春节停产期），检测机身精度、更换易损件、校验过载保护。大修后试打 50 件，全尺寸检测合格后交付生产。
